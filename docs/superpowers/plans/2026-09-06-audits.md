# R11 — Colourblind audit + pause-anywhere verification — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two accessibility items that are mostly verification. **(a)** Simulate
protan / deutan / tritan over the 85 hexes the game actually ships, publish the
table and the verdict as a doc, and swap **at most two** hex values — only where
a pair is adjacent, carries no shape difference, and genuinely collides.
**(b)** Prove pause reaches every state a player can be in, including the two
single-frame transitions between rooms and between runs, by pinning seven cases
that are currently unpinned.

**Architecture:** The audit is a **throwaway Node script in the session
scratchpad** — no new file lands in `src/` or `tests/` for it, because a CVD
simulation has no assertion to make (it produces a report) and would be either a
permanent no-op or a permanent flake surface inside the `node --test` battery.
The **doc** is the deliverable. Colour maths is **copied, not re-derived**:
`labOf` and `dE` are lifted verbatim from `tests/items-art.test.mjs:55-72` and
cited by line, so the R11 numbers and the shipped MAKO gate can never fork. The
pause work is **verification, not new code** — `onPause` (`src/main.js:329-340`)
and `input.js:48` (`KeyP` / `Escape`) are the whole mechanism, and the expected
diff is `tests/headless.test.mjs` only.

**Tech Stack:** Pure ES modules, `node --test` / `tests/*.test.mjs`. Zero npm
runtime deps. The audit script is plain Node with dynamic `import()` against the
repo's own modules — it never re-types a shipped hex.

**Spec:** `docs/superpowers/specs/2026-09-06-retention-wave1-design.md` §4

**Index:** `docs/superpowers/plans/2026-09-06-retention-wave1.md`

**Depends on:** R7 (`docs/superpowers/plans/2026-09-06-stopwatch-modes.md`).
**Not optional ordering:** the audit set includes the TIME chip's `#ff8a3c`.
Auditing before R7 would audit a palette that is about to change and force a
second pass. The pause pins are order-independent.

## Global Constraints

- **≤ 2 hex swaps for the whole wave**, and a swap is eligible only when **all
  three** hold: (1) the pair is drawn adjacent or overlapping in the same view;
  (2) the pair carries **no** shape, glyph, label or silhouette difference;
  (3) it meets the collision rule.
- **Excluded by construction, not by judgement:**
  - **player-vs-foe and foe-vs-foe pairs.** AGENTS.md: separation from the cast
    is "structure, never a re-hue", and `stationary`'s `#c58aff` is explicitly
    disclosed-and-not-gated. A CVD swap here is the one change AGENTS forbids by
    name.
  - **`POWER[*].col`** — every pickup carries its own `drawIcon` glyph, so shape
    separates.
  - **`HEAT_COL`** (chips carry `HEAT_MARK` `·` / `+` / `×`), **`PACT_COL`** and
    the TIME chip (chips carry `1 IRON` … `5 TIME` text).
  - In practice that leaves only **within-biome swatch pairs** eligible.
- **Collision rule:** report a collision when `dE(a, b) >= 14` in true colour
  **but** `dE(sim(a), sim(b)) < 14` for at least one of protan / deutan /
  tritan. The threshold **14** is not invented — it is the floor already shipped
  at `tests/items-art.test.mjs:755`.
- **Any swap must re-run `tests/items-art.test.mjs`** — the 56-swatch
  value-AND-hue gate and both VOID ΔE floors are exactly what a well-meant CVD
  swap breaks — plus `tests/menudraw.test.mjs` and a headed 2D+3D look.
- **Zero eligible collisions is a PASS**, and is the expected outcome: report
  §4 R11 says "expect to swap 1–2 hex values", and the AGENTS gate has already
  swept the hardest case. **The doc ships either way.**
- **The success metric is a design review, not an in-game number.** Report §4
  R11, quoted: "Design review, not an in-game number. Say so rather than
  inventing one." The doc must say so too.
- **The pause work adds no source lines.** If a pin fails, that is a genuine
  bug and stops the task — it is not licence to redesign `onPause`.
- **Already pinned, do not re-pin:** `tests/headless.test.mjs` I2 — PLAY ⇄ PAUSE
  inside GAME, `onPause` outside GAME leaving the world untouched, and `KeyP` at
  MENU routing to the app only.
- **ATTRACT is deliberately excluded** from pause. It is a demo, not a run.
- Never write the banned grid-bomb franchise name into any committed file.
- PWA: this plan's commits are **docs-only and test-only**, which per the spec's
  §7 rule do **not** bump. **The one exception:** if a hex swap lands, that
  commit changes precached bytes — read `src/pwa/shell.js:1`, bump `CACHE_NAME`
  + `sw.js:3` `REV` together, `current vN → vN+1`.

**A note on this plan's shape.** Task 2 is ordinary TDD. Task 1 is an audit, and
an audit has no red-to-green cycle to run — so its "test" is a **self-check
gate** the script runs before it simulates a single colour: three checkable
invariants on the 27 transcribed coefficients, plus two cross-checks against
numbers `tests/items-art.test.mjs` already ships. If the gate fails, the audit
does not run. That is stated here rather than dressed up as TDD.

```js
/* R11 CVD audit — THROWAWAY. Not committed; the doc is the deliverable.
   Run: node <scratchpad>/cvd-audit.mjs /Users/macbook/workspace/rollblock
   Every shipped hex is IMPORTED, never re-typed. labOf/dE are verbatim from
   tests/items-art.test.mjs:55-72 so the R11 numbers and the shipped MAKO gate
   cannot fork. */
import { pathToFileURL } from "node:url";
import { join } from "node:path";
import { readFileSync } from "node:fs";

const REPO = process.argv[2] || process.cwd();
const imp = (p) => import(pathToFileURL(join(REPO, p)).href);
const { BIOMES } = await imp("src/core/config.js");
const { POWER, FOES } = await imp("src/core/entities.js");
const { HEAT_COL } = await imp("src/core/heat.js");
const { PACT_COL } = await imp("src/core/pact.js");

// ---- colour maths, verbatim from tests/items-art.test.mjs:55-72 ----
const rgbOf = (hex) => {
  const h = String(hex).replace("#", "");
  return [
    parseInt(h.slice(0, 2), 16),
    parseInt(h.slice(2, 4), 16),
    parseInt(h.slice(4, 6), 16),
  ];
};
const labOf = (hex) => {
  let [r, g, b] = rgbOf(hex).map((v) => v / 255);
  const f = (v) => (v <= 0.04045 ? v / 12.92 : Math.pow((v + 0.055) / 1.055, 2.4));
  r = f(r);
  g = f(g);
  b = f(b);
  const X = (r * 0.4124 + g * 0.3576 + b * 0.1805) / 0.95047,
    Y = r * 0.2126 + g * 0.7152 + b * 0.0722,
    Z = (r * 0.0193 + g * 0.1192 + b * 0.9505) / 1.08883;
  const k = (t) => (t > 0.008856 ? Math.cbrt(t) : 7.787 * t + 16 / 116);
  return [116 * k(Y) - 16, 500 * (k(X) - k(Y)), 200 * (k(Y) - k(Z))];
};
const dE = (a, b) => {
  const A = labOf(a),
    B = labOf(b);
  return Math.hypot(A[0] - B[0], A[1] - B[1], A[2] - B[2]);
};

// ---- Vienot-Brettel-Mollon (1999) protan/deutan, Brettel tritan, severity 1.0
const MAT = {
  protan: [
    [0.11238, 0.88762, 0.0],
    [0.11238, 0.88762, 0.0],
    [0.00401, -0.00401, 1.0],
  ],
  deutan: [
    [0.29275, 0.70725, 0.0],
    [0.29275, 0.70725, 0.0],
    [-0.02234, 0.02234, 1.0],
  ],
  tritan: [
    [1.0, 0.14461, -0.14461],
    [0.0, 0.85659, 0.14341],
    [0.0, 0.85659, 0.14341],
  ],
};
const eotf = (c) => (c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4));
const oetf = (c) => (c <= 0.0031308 ? c * 12.92 : 1.055 * Math.pow(c, 1 / 2.4) - 0.055);
const hex2 = (v) => Math.max(0, Math.min(255, Math.round(v * 255))).toString(16).padStart(2, "0");
const sim = (hex, kind) => {
  const M = MAT[kind];
  const lin = rgbOf(hex).map((v) => eotf(v / 255));
  const out = M.map((row) => row[0] * lin[0] + row[1] * lin[1] + row[2] * lin[2]);
  return "#" + out.map((v) => hex2(oetf(Math.max(0, Math.min(1, v))))).join("");
};

// ---- the swatch set: 56 biome + 12 pickups + 9 foes + 3 heat + 4 pact + 1 TIME
const overA = (fg, bg, a) => {
  const F = rgbOf(fg),
    B = rgbOf(bg);
  return "#" + [0, 1, 2].map((i) => hex2((F[i] * a + B[i] * (1 - a)) / 255)).join("");
};
const biomeSwatches = (B) =>
  ["floor0", "floor1", "wall", "wallHi", "brickA", "brickB"]
    .map((k) => [B.name + "." + k, B[k]])
    .concat([[B.name + ".brickHi@.55", overA(B.brickHi, B.brickA, 0.55)]]);
const BIOME_SW = BIOMES.map(biomeSwatches);
const TIME_COL = (readFileSync(join(REPO, "src/render/menudraw.js"), "utf8")
  .match(/TIME_COL\s*=\s*"(#[0-9a-fA-F]{6})"/) || [])[1];

// ---- SELF-CHECK GATE: nothing is simulated until all six of these hold ----
let gate = 0,
  gateFail = 0;
const gk = (name, cond, detail) => {
  cond ? gate++ : gateFail++;
  console.log((cond ? "  GATE PASS " : "  GATE FAIL ") + name +
    (detail !== undefined ? " -> " + detail : ""));
};
for (const k of Object.keys(MAT)) {
  const M = MAT[k];
  gk(
    k + ": every row sums to 1.0, so neutrals are preserved",
    M.every((r) => Math.abs(r[0] + r[1] + r[2] - 1) < 1e-9),
    JSON.stringify(M.map((r) => +(r[0] + r[1] + r[2]).toFixed(9))),
  );
}
gk("protan/deutan collapse R and G (rows 0 and 1 identical)",
  MAT.protan[0].join() === MAT.protan[1].join() &&
    MAT.deutan[0].join() === MAT.deutan[1].join());
gk("tritan collapses G and B (rows 1 and 2 identical)",
  MAT.tritan[1].join() === MAT.tritan[2].join());
gk("mid grey is a fixed point under all three simulations",
  ["protan", "deutan", "tritan"].every((k) => sim("#808080", k) === "#808080"),
  ["protan", "deutan", "tritan"].map((k) => sim("#808080", k)).join(" "));
const VOID = BIOMES.find((b) => b.name === "VOID");
gk("the brickHi@.55 composite reproduces the spec's VOID value #a266e6",
  overA(VOID.brickHi, VOID.brickA, 0.55) === "#a266e6",
  overA(VOID.brickHi, VOID.brickA, 0.55));
gk("dE reproduces the shipped VOID floors (items-art.test.mjs:755, :760)",
  Math.min(...biomeSwatches(VOID).map(([, s]) => dE("#c39cff", s))) >= 14 &&
    dE("#c39cff", VOID.brickA) >= 40,
  Math.min(...biomeSwatches(VOID).map(([, s]) => dE("#c39cff", s))).toFixed(1));
gk("the TIME chip hex is read from menudraw, not re-typed (R7 must have landed)",
  /^#[0-9a-f]{6}$/i.test(String(TIME_COL)), String(TIME_COL));
gk("the 9 FOES colours are byte-identical to spawnEnemy's spec table",
  (() => {
    const src = readFileSync(join(REPO, "src/core/entities.js"), "utf8");
    const spawn = src.slice(src.indexOf("const spec = {"));
    return FOES.every((f) => spawn.indexOf('"' + f.col + '"') >= 0);
  })(),
  FOES.map((f) => f.col).join(" "));
if (gateFail) {
  console.log("\n  GATE FAILED — nothing simulated. Fix the coefficients or the");
  console.log("  order (R11 runs AFTER R7) and re-run.");
  process.exit(1);
}

// ---- the 85-colour table ----
const SET = []
  .concat(...BIOME_SW)
  .concat(POWER.map((p) => ["POWER." + p.t, p.col]))
  .concat(FOES.map((f) => ["FOE." + (f.t || f.name), f.col]))
  .concat(HEAT_COL.map((c, i) => ["HEAT[" + i + "]", c]))
  .concat(PACT_COL.map((c, i) => ["PACT[" + i + "]", c]))
  .concat([["CHIP.TIME", TIME_COL]]);
console.log("\n  SET SIZE: " + SET.length + " (expected 85)");
console.log("\n| swatch | true | protan | deutan | tritan |");
console.log("|---|---|---|---|---|");
for (const [n, h] of SET)
  console.log("| " + n + " | " + h + " | " + sim(h, "protan") + " | " +
    sim(h, "deutan") + " | " + sim(h, "tritan") + " |");

// ---- collisions, by pair class ----
const scan = (label, pairs, eligible) => {
  const hits = [];
  for (const [an, a, bn, b] of pairs) {
    const t = dE(a, b);
    if (t < 14) continue; // already indistinguishable in true colour; not a CVD finding
    for (const k of ["protan", "deutan", "tritan"]) {
      const s = dE(sim(a, k), sim(b, k));
      if (s < 14)
        hits.push({ pair: an + " / " + bn, kind: k, true: +t.toFixed(1), sim: +s.toFixed(1) });
    }
  }
  console.log("\n  " + label + " (" + pairs.length + " pairs, " +
    (eligible ? "ELIGIBLE for a swap" : "excluded by construction") + "): " +
    hits.length + " collisions");
  for (const h of hits)
    console.log("    " + h.pair + " — " + h.kind + ": " + h.true + " dE true -> " + h.sim + " dE sim");
  return hits;
};
const within = [];
for (const sw of BIOME_SW)
  for (let i = 0; i < sw.length; i++)
    for (let j = i + 1; j < sw.length; j++)
      within.push([sw[i][0], sw[i][1], sw[j][0], sw[j][1]]);
const foeVsBackdrop = [];
for (const f of FOES)
  for (const sw of BIOME_SW)
    for (const [n, s] of sw) foeVsBackdrop.push(["FOE." + (f.t || f.name), f.col, n, s]);
const pickupVsFloor = [];
for (const p of POWER)
  for (const sw of BIOME_SW)
    for (const [n, s] of sw)
      if (n.indexOf(".floor") > 0) pickupVsFloor.push(["POWER." + p.t, p.col, n, s]);
const chips = [].concat(
  HEAT_COL.map((c, i) => ["HEAT[" + i + "]", c]),
  PACT_COL.map((c, i) => ["PACT[" + i + "]", c]),
  [["CHIP.TIME", TIME_COL]],
);
const chipPairs = [];
for (let i = 0; i < chips.length; i++)
  for (let j = i + 1; j < chips.length; j++)
    chipPairs.push([chips[i][0], chips[i][1], chips[j][0], chips[j][1]]);

const eligibleHits = scan("WITHIN-BIOME SWATCH PAIRS", within, true);
scan("FOE vs BACKDROP (shape: drawEnemyBody silhouette)", foeVsBackdrop, false);
scan("PICKUP vs FLOOR (shape: drawIcon glyph)", pickupVsFloor, false);
scan("CHIP ROW (shape: HEAT_MARK and the 1 IRON..5 TIME labels)", chipPairs, false);
console.log("\n  VERDICT: " + (eligibleHits.length
  ? eligibleHits.length + " ELIGIBLE collision(s) — apply at most 2 swaps"
  : "PASS — zero eligible collisions, zero swaps"));
```
