# CONTROLS: acceptance checklist (2026-11-02, branch `feature/controls`, push Friday 2026-11-06)
Judges the build of gamepad play, rebinding on both devices, the CONTROLS page in the tile skin, and hints that follow the last-used device. Out of this branch: restyling other menus (`R:47`), MOVE STYLE and hand presets (`R:92`), keyboard diagonal speed (`R:84`). **Note 2026-11-02 (lead ruling):** the page is now in the CONSOLE PANEL kit, not the tile skin, and the all-menus restyle of `R:47` is not planned for this release. Where a dated note here differs from `R`, the note wins. **Note 2026-11-03:** DEADZONE is now SENSITIVITY and RUMBLE is now VIBRATION on screen; rows keep their ids, and notes below give what changed.
Proof: **NODE** = a test with a fake gamepad. **BROWSER** = headless Chrome, real page, synthetic events and a stubbed `navigator.getGamepads`; it proves wiring, never feel or activation. **HUMAN** = a person with a real controller.
Cites: `R` = `specs/2026-11-02-controls-menu-design.md` (wins). `GD` / `UX` / `A11Y` = `.superpowers/sdd/notes/v200-controls-design/ui/notes/`. `proto` / `page` / `page2` = its `mock/`. Other paths are under `src/`; `index.html`, `AGENTS.md`, `tests/` at the repo root. A `Q` tag marks a reading the record leaves open, listed at the end. Buttons are named by position only.
