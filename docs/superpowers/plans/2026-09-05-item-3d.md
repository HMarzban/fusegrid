## Global Constraints

- The **plan-view law**: a `Cone` / `Cylinder` / `Sphere` / `Torus` / high-`seg` lathe all collapse to a circle from 59.1°. Low-`seg` `lathe(pts, seg, r)` is an N-gon; `plate(pts, thick, r).rotateX(-Math.PI/2)` has its authored outline AS its footprint.
- A spinning kind may separate on **rotation-invariant properties only** (side count, radius, elongation). That is why CAPACITY and `power` spin and UTILITY / `line` / `pierce` do not.
- `lathe` profiles run **bottom → top** or three emits inward normals and the body renders as a hole. The flat families have the same trap in a different guise: `ExtrudeGeometry`'s cap normals follow the shape's **signed area**, and the twelve authored outlines do not share a winding, so `mesa()` normalises winding before extruding. A body whose lit cap faces the floor does not look like a bug, it looks like "that pickup is oddly dark" — which is why there is a gate for it.
- Every body stays **one `MeshLambertMaterial`, flat `pdef.col`, no map, no emissive.** The ring is the only accent channel and the only additive material on an item.
- `castShadow = true` on every body `InstancedMesh`; never on a ring (`InstancedMesh` defaults to false — do not set it).
- `SLOT_MESH.item` stays **2**. Item draws stay `12 * 2 === 24`. All twelve geometry `uuid`s stay pairwise unique.
- The `ITEM_MAKE` identifier is a source-grep gate (`tests/pickup-3d.test.mjs:314-330`) — rebuild the table's contents, **never rename it**. Keep every new geometry inside the existing `ITEM_GEO[pd.t] = sharedGeo(ITEM_MAKE[pd.t]())` loop so `_shared` still protects it from `disposeGroup`; `sharedGeo` the four ring geometries too (the `iringGeo` they replace was shared).
- `atlas.item_<t>` keys stay baked by `paintItemFace` and applied to **no** material. Do not wire a `.map`.
- One clock: `world.time`. `performance.now()` is forbidden. Phase is `ph = (it.x * 0.7 + it.y * 1.3) / CFG.TILE`, never `slot`.
- **Fat-world stays 143 in this plan.** `SLOT_MESH.player` does not move here, so the existing formula gates pass unchanged. Add **no** new fat-world literal — the 143→141 move is P4's, and a literal added here would have to be edited there. (Spec §4.20 lists `141` under P2; §6's P4 row — "**all four** fat-world sites 143→141" — is the binding one.)
- `tests/pickups.test.mjs`, `menudraw.test.mjs`, `touch.test.mjs`, `r3d.test.mjs`, `media.test.mjs`, `enemies-art.test.mjs` all stay green with zero edits.

   lathes (seg IS the identity axis: 3/4/6/8); flat families are an outer
   shelf fused with an inner mesa, whose 0.205r riser is the lit facet that

function mesa(out, ins, r) {
  /* ExtrudeGeometry's cap normals follow the shape's signed area, and the
     twelve authored outlines do not share a winding — so half the flat
     bodies would face their lit cap at the floor. Same class of trap as the
     lathe bottom -> top rule; normalised here so ITEM_SHAPE stays one table
     byte-identical for both renderers. */
  const cw = (p) => {
    let a = 0;
    for (let i = 0; i < p.length; i++) {
      const q = p[(i + 1) % p.length];
      a += p[i][0] * q[1] - q[0] * p[i][1];
    }
    return a < 0 ? p.slice().reverse() : p;
  };
  const parts = [plate(cw(out), 0.55, r).rotateX(-Math.PI / 2)];
  for (const p of ins)
    parts.push(
      plate(cw(p), 0.4, r)
        .rotateX(-Math.PI / 2)
        .translate(0, 0.28 * r, 0),
    );
  return mergeGeos(...parts);
}
