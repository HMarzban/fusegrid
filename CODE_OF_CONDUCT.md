# Code of Conduct

> **Be the player everyone wants at the next cabinet over.**

Fusegrid is a game about blowing up bricks, not people. Everyone who plays,
files an issue, reviews code or sends a pull request is welcome here,
whatever their age, background, identity, experience or skill level. A
first-timer's question gets the same respect as a veteran's patch.

## 🟢 Good play

- Be kind and assume good intent. Text loses tone, so read it generously.
- Critique the code, the design or the idea, never the person.
- Say what you saw, not what someone "always" does.
- Give credit: name who found the bug, who playtested, who had the idea.
- Welcome newcomers. Point them at [CONTRIBUTING.md](CONTRIBUTING.md) and the
  [docs map](docs/README.md).
- Accept a "no" on a feature gracefully. A small game stays good by saying it
  often.

## 🔴 Fouls

- Harassment, insults, slurs, or sexual language or imagery.
- Personal or political attacks, trolling, or deliberately derailing a thread.
- Publishing anyone's private information without their explicit permission.
- Pressuring, stalking or repeatedly contacting someone who asked you to stop.
- Anything else a reasonable person would call unwelcoming.

## 🧯 Calling a foul

If something here makes you uncomfortable, contact the maintainer privately
through their GitHub profile, [@HMarzban](https://github.com/HMarzban), or use
GitHub's *Report content* option on the comment, issue or pull request. Reports
are handled privately, and nobody is penalised for reporting in good faith.

The maintainer may edit or remove comments, commits, issues and pull requests
that break this code, and may warn, temporarily block or permanently ban
anyone whose behaviour does.

## 🗺️ Where it applies

This code applies in every project space: issues, pull requests, reviews,
discussions, and anywhere you represent the project in public.

This code is adapted from the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
